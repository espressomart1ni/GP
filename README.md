# Riddhima Kapoor | Portfolio (LCF application)
- `index.html`: the page. `css/style.css`, `js/main.js`: styling and snap-scroll.
- `images/`: every picture used (dashboard screenshots, R output, internship desk, three Katwa loom photos).
- Open locally: double-click `index.html`. Deploy: upload the whole folder to a GitHub Pages repo (keep `.nojekyll`).
- Edit text in `index.html`; swap a picture by replacing the file in `images/` with the same name.
